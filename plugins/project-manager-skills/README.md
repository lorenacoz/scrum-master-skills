# project-manager-skills

40 AI skills for project managers, by phase: start, plan, run delivery, monitor and report, communicate, launch and close, and work tools (Jira, Confluence, Notion, Linear).

## Install

In Claude Code:

```
/plugin marketplace add lorenacoz/scrum-master-skills
/plugin install project-manager-skills@scrum-master-skills
```

Skills load on their own when a request matches. Call one directly with `/project-manager-skills:<skill-name>`.

## Skills (40)

| Skill | What it does |
|---|---|
| `project-manager` | Set up a project: charter, plan, RAID log (risks, assumptions, issues, dependencies), change control and status. |
| `stakeholder-map` | Map who has power and interest, and plan how to engage each group. |
| `daci-framework` | Agree who Drives, Approves, Contributes and is Informed for a decision, before it stalls. |
| `working-agreements` | Charter a new team: purpose, working agreements and a first Definition of Done. |
| `pm-onboarding` | Build a 30-60-90 day plan when you join a new project, program or company. |
| `wayfinder` | Work is too big or unclear for one sprint: map the open decisions, resolve them in order, then create tickets. |
| `quarterly-planning` | Plan a quarter: capacity, commitments versus stretch, cross-team dependencies. |
| `outcome-roadmap` | Turn a feature list into a Now / Next / Later roadmap of outcomes, each with a measure. |
| `dependency-map` | Find cross-team dependencies and rank them by risk. |
| `pre-mortem` | Imagine the project failed, list why, and give each risk an owner and a mitigation. |
| `plan-grilling` | Stress-test a plan one round of questions at a time until every decision is settled. |
| `prioritization-frameworks` | Choose and apply a prioritization method (RICE, MoSCoW, WSJF, Kano and others). |
| `create-prd` | Write a requirements document that frames the problem before the solution. |
| `delivery-manager` | Plan releases, run a Go/No-Go, choose a deployment strategy, handle an incident. |
| `impediment-log` | Log, triage and escalate a blocker, and draft the escalation message. |
| `protect-the-sprint` | Handle mid-sprint requests and scope creep, and draft the reply to the stakeholder. |
| `decision-questionnaire` | Get a decision from a busy stakeholder in writing, without scheduling a meeting. |
| `problem-solver` | Diagnose a recurring problem before fixing it: problem statement and verified root causes. |
| `meeting-analyzer` | Turn meeting notes into a register of who committed to what; diagnose meetings that decide nothing. |
| `summarize-meeting` | Summarize one meeting into decisions, action items with owners, and open questions. |
| `test-scenarios` | Write QA test cases from a spec, including edge, error and security paths. |
| `senior-pm` | Score portfolio health, risk exposure and resource capacity; frame executive status reports. |
| `status-update-generator` | Write a weekly status update: RAG status, progress, risks and asks. |
| `program-manager` | Coordinate several related projects: roadmap, dependencies, governance. |
| `cycle-time-analyzer` | Analyze cycle time and throughput to find where work gets stuck and forecast delivery. |
| `metrics-conversation` | Present delivery metrics to leadership without them being misused. |
| `roadmap-communication` | Produce executive, customer and internal versions of one roadmap. |
| `team-communications` | Design how the team communicates: channels, meeting load, status structure, escalation. |
| `pm-1on1s` | Plan 1:1s with your manager, engineering leads and partners. |
| `launch-playbook` | Coordinate a launch from 30 days before to 30 days after: owners, run-of-show, comms, rollback, retro. |
| `beta-program` | Run a pilot or closed beta with exit criteria agreed before it starts. |
| `feature-flag-strategy` | Plan a phased rollout with a kill switch. |
| `release-notes` | Turn tickets and changelogs into release notes people will read. |
| `eol-communication` | Retire a system or feature: dated milestones, migration path, messages per audience. |
| `post-mortem` | Run a blameless review after a missed launch, incident or failed project. |
| `jira-expert` | Jira workflows, JQL queries, boards, dashboards and automation. |
| `confluence-expert` | Set up or clean up Confluence spaces, page trees, permissions and stale pages. |
| `atlassian-templates` | Build reusable Jira issue and Confluence page templates people actually fill in. |
| `notion-pm` | Design Notion databases and views for projects, decisions and roadmaps. |
| `linear-expert` | Set up Linear teams, cycles, projects and triage. |
