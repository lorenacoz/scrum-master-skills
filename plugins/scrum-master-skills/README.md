# scrum-master-skills

AI skills for Scrum Masters: every Scrum and SAFe event, facilitation, team conflict, risks, backlog, metrics and stakeholders.

## Install

In Claude Code:

```
/plugin marketplace add lorenacoz/scrum-master-skills
/plugin install scrum-master-skills@scrum-master-skills
```

Skills load on their own when a request matches. Call one directly with `/scrum-master-skills:<skill-name>`.
